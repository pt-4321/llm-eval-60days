# errors/ 使用说明

这个文件夹是整个计划里**最值钱**的地方。

## 命名规则

```
01_python_version.txt      序号_发生了什么
02_401_unauthorized.txt
03_ollama_timeout.txt
```

## 每个报错文件里放三样东西

1. **原文**：完整报错，不要只截最后一行，不要手打（复制粘贴）
2. **我当时在干什么**：一条命令 / 一句话复现步骤
3. **我猜的原因**：哪怕猜错也要写，写错才知道自己哪里不懂

## 怎么用

- `hello_api.py` 和 `check_env.py` 会自动把网络/HTTP 错误存到这里，文件名带时间戳
- 拿到报错后，把文件内容整段发给我，我给最小修复，不给长篇教程
- 每周末回看一次：**三个月后你会发现，90% 的报错只有 5 种原因**

## 红线

> 不删除失败记录。删掉报错，等于删掉自己的教材。
