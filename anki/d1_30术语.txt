Token	模型处理文本的最小单位；中文大约 1 个字 ≈ 0.6—1 个 token
上下文窗口	模型一次能「看见」的最大 token 数，超过就截断或报错
Temperature	随机性旋钮，越高越发散、越低越稳定
Top-p	核采样：只在累计概率前 p 的候选词里挑，控制候选范围
System Prompt	放在对话最前面的顶层指令，设定角色、规则和边界
幻觉 Hallucination	编造看似合理但不存在的事实（条款号、数字、出处最常见）
评测集 Eval Set	用来打分的题目 + 标准答案的集合
Golden Set	人工逐条确认过的高质量基准集，改一次要评审一次
Rubric	评分细则：把「好」拆成可打分的维度，每档有明确描述
LLM-as-a-Judge	用更强的模型当裁判给弱模型打分；便宜但必须抽检验证
位置偏差	裁判偏爱排在前面的答案；对策是交换顺序测两遍
长度偏差	裁判偏爱更长的答案；对策是控制长度或按长度分层
自我偏好	裁判偏爱同家族模型的输出；对策是换裁判模型交叉验证
Pass@k	k 次采样中至少一次答对的比例，衡量「能不能做出来」
胜率 Win-rate	两两对比中获胜的比例，比绝对分更稳
一致率	多次采样 / 多人标注结果相同的比例
Cohen's Kappa	扣除随机一致后的一致性系数，评测岗的专业暗号
拒答率	模型拒绝回答的比例；太高说明过度保守
过度拒答	该答的也拒了，安全指标好看但可用性崩了
幻觉率	输出中含编造内容的比例，需要逐条核对出处
RAG	检索增强生成：先查资料再回答，把「记」换成「查」
Recall@k	前 k 条检索结果中命中相关文档的比例
MRR	第一个相关结果排名的倒数和，越接近 1 越好
Faithfulness	回答是否忠于检索到的原文，而不是自由发挥
Agent	能规划、调工具、多步执行的模型系统
Badcase	表现不好的具体样本；错误分析的原材料
数据污染	测试题混进训练数据，导致跑分虚高
红队 Red Teaming	用对抗方式主动找模型的安全漏洞
对齐 Alignment	让模型行为符合人类意图与价值
灰度	小流量上线观察，出问题只影响一小部分用户
