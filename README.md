# llm-eval-60days

从零到「可面试」的 60 天：Python → 大模型评测 → 建筑工程领域评测集 → 简历。

主线项目：**《建筑规范问答场景下国产大模型事实性与安全性评测》**

## 我在做什么

本职是土木工程商务岗（2026 届），零编程基础起步，用 12 周业余时间（每天 25—60 分钟 + 周日 6 小时）转生成式 AI 测试评估方向。
切入点不是「学写代码」，是**把我对建筑规范的判断力，变成可复用的评测集和标注规范**。
